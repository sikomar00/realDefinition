# 시맨틱 레이어 시험 결과 (INT-008, 부분 완료)

## 요약
**결론을 내지 못했습니다. 종합 판정은 "불명"입니다.** LLM이 SQL을 새로 짜지 않고 질문을 "지표와 기간"으로만 옮기게 했더니, 끝까지 돌린 모델 1개(glm)에서 정확도·일치율 99.3%로 사전에 정한 "성공" 기준(둘 다 90% 이상)을 넘었습니다. 하지만 같은 질문을 기존 방식(자유 SQL)으로 풀어도 95.0%여서 차이는 +4.2%p뿐이었습니다. **질문이 너무 쉬워서 두 방식을 가르지 못했습니다.** 두 번째 모델은 호출 한도(429)로 끝내지 못해 여기서 종료했습니다.

## 1. 한 일
| 항목 | 내용 |
|---|---|
| 조건 S | LLM은 `{지표, 월}`만 고르고, SQL은 검증된 식([gold.py](../experiment/gold.py))이 만든다. 계산은 구성상 맞으므로 **질문 → 지표·기간 옮기기(라우팅)만 잰다** |
| 조건 B | 사전 v2 + 자유 SQL(기존 방식). 답할 수 있는 질문 24개에서만 비교 |
| 질문 | 새 질문 30개(메인 20 + 보류 10, 답할 수 없는 질문 6개 포함). **Claude가 썼다(작성자 미분리)** |
| 기준 | 실행 전 고정: 일치율 ≥ 90% **그리고** 정확도 ≥ 90%면 성공 ([D-041](02-thinking-log.md)) |
| 모델 | 원래 `gpt-oss-20b`·`nemotron-120b`가 호출되지 않아 `glm-5.3-flash`·`deepseek-v4.1-flash`로 대체 ([D-042](02-thinking-log.md)) |
| 코드 | [gold_semantic.py](../experiment/gold_semantic.py), [run_semantic.py](../experiment/run_semantic.py), 테스트 12개 추가(실험 44개·앱 59개 통과) |

## 2. 결과 (기록: `experiment/runs_semantic/main-*.jsonl`)
| 실험 | S 정확도 | S 일치율 | 비고 |
|---|---|---|---|
| glm 온도 0.7 | 99.3% (149/150) | 99.3% | 답할 수 없는 질문 30/30 맞힘, 오답 1건은 JSON 형식 오류 |
| 같은 질문, B | 95.0% (114/120) | 95.0% | S−B = **+4.2%p** → 모델 판정 **성공** |
| glm 온도 0 | 100% (150/150) | 100% | 참고용(판정에 안 씀) |
| deepseek 온도 0 | 100% (150/150) | 100% | 참고용(판정에 안 씀) |
| deepseek 온도 0.7 | — | — | **270건 중 48건 호출 실패(HTTP 429), 미완료.** 판정 불가 |

종합 판정(두 모델이 모두 성공해야 성공): 완료된 모델이 하나뿐이라 **불명**.

## 3. 이 결과를 믿으면 안 되는 이유
1. **천장 효과.** 기존 방식(B)도 95%였습니다. 예전 `gpt-oss-20b`의 59~66%, 일관성 71~74%라는 문제가 이번 모델에서는 재현되지 않았습니다. 질문이 쉬워서 S와 B를 가르지 못했습니다.
2. **작성자 미분리.** 질문·사전·골드를 같은 Claude가 만들었습니다. 사전에 유리한 표현이 섞였을 수 있습니다.
3. **라우팅만 쟀습니다.** S의 계산은 구성상 맞습니다. "시맨틱 방식이 더 정확하다"가 아니라 "해석 단계만 남는다"는 뜻입니다. 골드가 곧 정의라서 사용자가 진짜 원한 뜻은 재지 못했습니다.
4. **모델 1개.** 모델 크기 정보를 확인하지 못했고(D-042), 한 모델의 결과로 일반화할 수 없습니다.
5. **내 실수.** deepseek의 두 실험을 동시에 돌려 한도를 넘겼습니다. 재시도에도 계속 429라 복구하지 못했습니다. 실패 호출은 오답으로 세지 않았습니다.

## 4. 얻은 것
- 방법 자체는 작동합니다: 모델이 JSON을 안정적으로 내고, 사전에 없는 지표·기간 밖 질문에서 "답할 수 없음"을 냈습니다(30/30). 오류 경로(형식 오류, 재시도 중복 집계)도 테스트로 막았습니다.
- 다음에 이 방식을 다시 시험한다면 **더 어려운 질문(모호한 표현, 다른 사람이 쓴 문장, 사전 밖 경계 사례)** 과 **작은 모델**이 필요합니다. 그래야 S와 B가 갈립니다. 이는 [INT-009](../Intent.md)(작성자 분리·공개 실데이터)와 이어집니다.

## 📘 개념 학습 — 천장 효과(ceiling effect)
시험이 너무 쉬우면 누구나 만점 근처가 되어 실력 차이를 못 잽니다. 이번처럼 기존 방식이 95%면 새 방식이 99%여도 "더 낫다"고 말할 근거가 약합니다. 어려운 문제를 섞거나 약한 모델로 재야 차이가 드러납니다.
